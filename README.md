## Projects

### [FarmAlytics](https://github.com/LuisPCNeri/IES_FARMALYTICS) *(group project, 4 people)*
A real-time livestock monitoring platform built for a university course. The system includes a multi-threaded C worker that processes UDP sensor data, a Spring Boot REST API with 80+ endpoints, TimescaleDB for time-series storage, Redis for caching and pub/sub, RabbitMQ for message brokering, and a React frontend with live WebSocket updates. The whole stack runs in Docker.

### Monster Game — [game](https://github.com/LuisPCNeri/monster_game) · [map editor](https://github.com/LuisPCNeri/map-editor)
A monster-catching and battling game written in C using SDL2, along with a custom tile map editor built in C++. The editor supports multi-tile selection, rectangle and paintbrush selection modes, zoom, and texture assignment. Both are works in progress.
